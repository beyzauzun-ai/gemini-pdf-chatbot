# Gemini PDF Chatbot 🤖
PDF-based chatbot using Gemini API and Streamlit


This project is a PDF-based chatbot built using **Google Gemini API** and **Streamlit**.  
It allows users to upload a PDF and ask questions about its content.

## 🚀 Features
- 📄 Upload PDF files
- 💬 Ask questions about the document
- ⚡ Fast responses using Gemini API
- 🌐 Simple web interface with Streamlit

## 🛠️ Technologies Used
- Python
- Streamlit
- Google Gemini API

## ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
